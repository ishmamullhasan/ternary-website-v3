# Ternary Website v3 — Design Fidelity Audit

**Date:** 2026-06-19

**Source of truth:** Figma file `7R20YrTmdI2ilnq554ZObq` ("ternary-website-new"), the newer "Agentic Engineering" frame set (homepage node `339:8016`); older duplicate frames disregarded.

**Method:** multi-agent audit — one agent per page/area comparing Figma → live (dev server `:3001`) → source, plus a completeness critique pass.

**Scope note:** BOTH code and CMS content are in scope to fix.

## Executive summary

Nearly every page is **major-drift**: the live build diverges substantially from the Figma source on almost all surfaces. The pervasive root cause is the **type system** — the design is a deliberate two-family system (Poppins for display headlines, Inter for everything else) with signature tracking and weight rules, but the live site never loads Inter and renders all text in Poppins, with ad-hoc tracking and the wrong weights. Fixing the foundation (fonts, type-scale tokens, tracking, weights) resolves the single highest-leverage class of findings before any page-level work begins.

## Cross-cutting themes (fix once)

These recur across nearly every page and should be solved at the foundation layer, not page-by-page.

### T1 — Inter font never loaded (the single highest-leverage bug)

**Every page** flags this as critical/high. The design is a two-family system (Poppins = display headlines only; Inter = all body/nav/button/card/footer/eyebrow/label/meta), but `layout.tsx` loads only Poppins via `next/font`, and `globals.css` sets `body { font-family: var(--font-poppins) }`. So 100% of Inter-spec text renders in Poppins.
**Affects:** Global tokens, Nav/Footer, Homepage, About, Solutions, Industries, Capability, Stories, Case study, Insight, Press Release, Careers, Career+Apply, Contact, Scales, Legal, Mobile — **all 18 findings.**

### T2 — No type-scale / letter-spacing / line-height tokens

Signature tracking is absent everywhere: display −2px, section −1.5px, subsection −1.2px, body −0.8px, 14px −0.7px, 12px −0.6px; tight 1.15 line-height. Code uses ad-hoc `tracking-tight` (~−0.025em) or nothing. Headings also use `font-bold`/`font-semibold` where design specifies Medium (500).
**Affects:** Global, Homepage, About, Solutions, Industries, Capability, Stories, Insight, Press Release, Careers, Career+Apply, Contact, Scales, Legal, Mobile.

### T3 — Surface/text color tokens exist but are bypassed

`@theme` defines the correct palette, yet code (a) hardcodes hex literals (`#0F0E0E`, `#1B1A17`, `#757571`, `#D5D5D5`, `#14120B`), (b) uses generic Tailwind neutrals/zinc (`text-neutral-400`, `border-zinc-800`, `text-white`), and (c) leaves a **dead/wrong legacy shadcn HSL block** in `:root` where `--primary: 0 0% 100%` (pure white, not eggshell #f4f3ec), `--background: #000` (not #050505), `--foreground: #393939` (unusable). Pure-white headings instead of eggshell recur on Solutions/Capability/Insight/Press Release/Stories.
**Affects:** Global, Nav/Footer, About, Solutions, Industries, Capability, Stories, Insight, Press Release, Careers, Contact, Scales, Legal, Mobile.

### T4 — Page background wrong: `bg-black` (#000) instead of `bg-page` (#050505)

Root `body` hardcodes `bg-black` + inline `text-[#F4F3EC]`; the `bg-page` token is unused.
**Affects:** Global, Nav/Footer, Homepage.

### T5 — Radius drift: nothing equals the design's 5px (Radius/md) / 4px (sm)

Components mix `rounded` (4), `rounded-md` (6), `rounded-lg` (8 via `--radius`), `rounded-xl` (12), `rounded-2xl` (16), `rounded-3xl` (24), `rounded-full`. Buttons especially: design = 5px rect (or pills only on Contact), code = `rounded-lg`/`rounded-2xl`. Form inputs design = 4px, code = `rounded-lg`.
**Affects:** Global, Nav/Footer, Solutions, Capability, Stories, Careers, Career+Apply, Contact, Insight, Legal.

### T6 — Signature noise/grain gradient device is missing site-wide

The brand's defining visual (per-content-type noise.svg over rich multi-stop gradients) has **no shared token/utility/asset.** Code substitutes flat 2–3 stop Tailwind gradients, a single reused pink→purple→orange/blue fallback, photographic images, or — worse — pulls noise from **external URLs** (`grainy-gradients.vercel.app`, `images.unsplash.com`) creating runtime/privacy/CLS dependencies.
**Affects:** Global, Homepage, Solutions, Industries, Capability, Stories, Case study, Insight, Press Release, Careers, Contact, Scales.

### T7 — Button component is wrong at the primitive level

`button.tsx` default: `text-primary-foreground` (= #000 black, should be cream #f4f3ec), adds shadow + `hover:bg-main/90`, `rounded-md` (6px), Poppins `font-medium`. Design = bg #1b1a17, 5px radius, Inter Semibold 14, cream text, no shadow. Nav CTA additionally gained a white border the design lacks.
**Affects:** Global, Nav/Footer, plus every page's CTA.

### T8 — Focus-visible / keyboard a11y absent everywhere

Only `button.tsx` has a focus ring (`ring-ring` against #393939 — near-invisible on a near-black page). Nav links, footer links, cards, form inputs, pills, dropdown triggers: no visible focus. Inputs use `focus:outline-none` with only a border-color change.
**Affects:** all 18.

### T9 — No `prefers-reduced-motion` handling; motion re-fires

Sections wrap in Motion `whileInView` with `viewport once:false`, so animations re-trigger on every scroll-in (jittery). No reduced-motion guard, no shared duration/easing tokens. Header scroll listener, chevron/accordion, mobile panel all unguarded.
**Affects:** all pages using Motion (≈ all).

### T10 — No loading / empty / placeholder states for CMS content

Components map CMS arrays by fixed index with no guards; missing items render blank titles/excerpts or silently disappear (footer columns, capability sections, related grids). Several ship **literal placeholders to production**: "Copyright", "Title", "Excerpts", "Heading", "CTA Heading", "Read Time", "Category Label".
**Affects:** Nav/Footer, Homepage, About, Solutions, Industries, Capability (broken shell on agentic-architecture), Stories, Case study, Insight, Press Release, Careers, Contact.

### T11 — Container width inconsistent: design is 1480px

The `--container` cap is correct in theme, but pages variously use `max-w-7xl` (1280px) (Capability, Case study, Career+Apply) or full-bleed with no wrapper (Nav, Footer). Chrome doesn't align to the content column.
**Affects:** Nav/Footer, Homepage, About, Capability, Case study, Career+Apply, Mobile.

### T12 — CMS content correctness: wrong copy + shipped typos

Beyond design-vs-code, the **live CMS data itself is wrong**: footer/nav typos ("Comsumer", "Mordern Slavery", "Career & Opportunities", singular "Solution"), wrong taxonomy (Capabilities → "Product Engineering" vs design "Platform Engineering"), wrong industry labels, hardcoded duplicated panel copy, every story showing "12 min", all four contact routes showing the same email. This is a content/seed-data workstream distinct from code.
**Affects:** Nav/Footer, Homepage, About, Solutions, Industries, Capability, Stories, Press Release, Insight, Careers, Contact.

### T13 — Hardcoded / wrong external + placeholder asset references

`mailto:hello@ternary.studio` (wrong domain — should be ternary.solutions), `dummyimage.com` and `hearstapps` fallbacks, Unsplash "grain", `grainy-gradients.vercel.app`. Off-brand pink/purple/blue and violet/fuchsia gradient fallbacks recur as avatar/image placeholders.
**Affects:** About, Solutions, Capability, Insight, Contact.

## Per-page findings

### Global design tokens & type system

**Fidelity:** major-drift · **Live:** /en · **Figma:** 339:8028

**Summary:** The brand color palette (page/ink/cream/body/subtle/badge/main) was correctly ported into globals.css @theme and matches the Figma variables exactly, and the 1480px container cap is right. **Missing UI/UX:**

- Focus-visible: the only focus styling is button.tsx's focus-visible:ring-ring against --ring #393939 (very low contrast on a near-black page). Nav links, footer links, and form inputs have no visible keyboard-focus indicator — fails a11y. Define a high-contrast focus ring token (e.g. cream/#f4f3ec) and apply site-wide.
- Hover states are inconsistent and undesigned: button uses opacity hover (bg-main/90), inputs hover to ad-hoc #52525b/#757571, nav items have no documented hover token. The design provides no hover/active spec either — define hover/active tokens (e.g. cream-hover #e8e7df already exists for light buttons; add a dark-surface hover).
- No loading/skeleton or empty states for the CMS-driven content card grid, header menu, or footer columns; if Payload returns no items the columns silently render nothing (footer FooterMenuColumn returns null) with no placeholder.
- Reduced-motion / motion tokens: header has a scroll listener and several blocks use transition-all/translate hovers, but there is no prefers-reduced-motion handling and no shared motion duration/easing tokens.
- Grain/noise overlay treatment: the design's signature noise.svg gradient cards are central to the visual language but there is no global noise asset or shared gradient/noise utility in the token layer (noise referenced only inside CareersHero/CategoryLanding) — needs a reusable token/utility so all featured cards share the exact overlay.
- Responsive type scale: the design tokens are desktop-only (40px display, 16/14 body); there is no defined mobile step for the display headline, so mobile relies on ad-hoc text-2xl/text-3xl per block rather than a token-driven fluid/responsive scale.
- Dark-theme form input contrast: inputs use border-line-strong (#3f3f46) on transparent with body text #d5d5d5 — placeholder/disabled/error states are undefined in both design and code; add disabled and invalid state tokens.
